## **Introduction**

The portfolio website of **Kelly Kevin** and **Riches** is designed to highlight our technical skills and professional projects. It serves as a digital resume and a showcase of our collaborative and individual accomplishments in software engineering, specifically through the ALX program.

## **Features**

- **Responsive Design:** Optimized for desktops, tablets, and mobile devices using modern CSS.
- **Interactive Project Showcase:** Detailed project descriptions with interactive elements and SweetAlert integrations.
- **Modern UI/UX:** Clean design using Google Fonts (Poppins & Inter), smooth transitions, and scroll-reveal animations.
- **Interactive Greeting:** A special welcome message for visitors using SweetAlert2.

## **Technologies Used**

- **Front-end:**
  - HTML5
  - CSS3 (Custom variables, Flexbox, Grid)
  - JavaScript (ES6+, DOM manipulation)
- **External Libraries:**
  - SweetAlert2 (for interactive modals)
  - Google Fonts (Poppins, Inter)
- **Other Tools:**
  - Git & GitHub for version control

## **Setup Instructions**

To view the project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/RichesUR7/portfolio.git
   cd portfolio
   ```

2. **Open the project:**
   Simply open `index.html` in your favorite web browser.

3. **Development (Optional):**
   If you want to run a local server for live updates:
   ```bash
   # Using Python
   python3 -m http.server 3000
   ```
   Navigate to `http://localhost:3000`.

## **Usage**
